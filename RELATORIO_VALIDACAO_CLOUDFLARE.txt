LIMITAÇÃO DESTA EXECUÇÃO
O ambiente de preparação não conseguiu acessar registry.npmjs.org (erro de DNS EAI_AGAIN). Por isso, não foi possível baixar o esbuild e executar localmente o build final que gera dist/_worker.js. O pacote inclui a dependência esbuild fixada na versão 0.28.2 e o comando npm run build; o ambiente de build do Cloudflare deverá instalar essa dependência e executar o empacotamento quando o GitHub for conectado. Não declarei o deployment como concluído.

AINDA EXIGE CONFIGURAÇÃO NA CONTA DO USUÁRIO
1. Executar database/VERTICE_4_1_SCHEMA_TURSO.sql no banco Turso real.
2. Cadastrar TURSO_DATABASE_URL, TURSO_AUTH_TOKEN e ADMIN_TOKEN nos segredos do Cloudflare Pages.
3. Fazer o primeiro deployment pelo Git integration do GitHub.
4. Testar /api/health e /admin no domínio publicado.
5. Configurar CRON_SECRET e agendador externo somente se quiser automação.

SEGURANÇA
Não há senha padrão. ADMIN_TOKEN é a chave privada de acesso ao painel e precisa ter pelo menos 32 caracteres. Nunca comite tokens, senhas ou chaves no GitHub. Qualquer token Turso que já tenha sido compartilhado deve ser revogado e substituído.

Os testes locais não substituem os testes com as credenciais reais, banco remoto e deployment da conta Cloudflare. Não é possível prometer ausência absoluta de bugs.
